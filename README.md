# Bus Booking App

A modern bus booking application for searching, browsing, and reserving bus tickets. This project demonstrates full-stack development practices including user authentication, real-time seat availability, and payment integration.

## Features
- Search and filter bus routes by date and destination
- Real-time seat availability and selection
- User account management
- Secure payment processing
- Booking confirmation and history
- Responsive design for mobile and desktop
